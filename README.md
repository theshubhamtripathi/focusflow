# FocusFlow — iOS Productivity & Focus Tracker 🍎

## 📌 Overview

FocusFlow is a productivity app designed to help users manage tasks, maintain focus, and track daily progress using Pomodoro techniques.

---

## ✨ Features

* Task Management
* Pomodoro Timer
* Daily Streak Tracking
* Notifications
* Progress Analytics

---

## 🛠️ Tech Stack

* Swift
* SwiftUI
* CoreData
* UserNotifications

---

## 🧩 App Architecture

UI (SwiftUI)
↓
ViewModel (MVVM)
↓
CoreData (Persistence Layer)

---

## 📂 Folder Structure

```
focusflow-ios/
│── Views/
│── ViewModels/
│── Models/
│── Services/
│── Resources/
```

## ⚙️ Installation

1. Clone:

```

```

```
Open .xcodeproj file
```

3. Run on Simulator / Device
